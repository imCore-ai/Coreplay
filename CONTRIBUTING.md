# Contributing to Coreplay

Thank you for helping. Coreplay is a small, fast player for movies and image sequences, and
every fix, test file and translation makes it better for everyone.

## Ways to help

- **Report a bug.** Use the [bug report form](https://github.com/imCore-ai/coreplay/issues/new?template=bug_report.yml).
  The version (Help > About), your system and the kind of file matter most.
- **Share a file that plays wrong.** A short sample (a few frames) is often the fastest way to a fix.
- **Suggest a feature** with the [feature request form](https://github.com/imCore-ai/coreplay/issues/new?template=feature_request.yml),
  or talk it over first in [Discussions](https://github.com/imCore-ai/coreplay/discussions).
- **Fix something.** Issues labelled [`good first issue`](https://github.com/imCore-ai/coreplay/labels/good%20first%20issue)
  are small and well described: a good place to start.
- **Translate.** Coreplay speaks 17 languages; the files are in `i18n/`.

## Building and testing

[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) shows how to build on Windows, macOS and Linux, and
how to run the end-to-end tests (`tests/e2e/`). Please run the tests that touch your change.

## Pull requests

- One change per pull request, with a short description of what it fixes or adds.
- Match the style of the code around your change.
- Add or update a test in `tests/e2e/` when you change behaviour.
- By sending a pull request you agree that your contribution is licensed under the
  [Apache License 2.0](LICENSE), like the rest of the source code.

## Be kind

Be respectful and patient. We are all here to make a good tool.
